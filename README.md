# Willow-warbler-tracking-and-genomics
The datafile of all tracked and resequenced willow warblers are in the file "appendix 1". The data include tagging location, estimated longitude of the Mediterranean crossing, wintering location, and genotypes for three regions (WGS-Chr1,	WGS-Chr5,	WGS-MARB) coded as tro, hyb and acr
